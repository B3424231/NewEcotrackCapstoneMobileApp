# EcoTrack Mobile App Skills

## Project Overview
EcoTrack is an IoT-based air-conditioning monitoring system.

## Development Rules
- Use React Native for the mobile application.
- Keep the UI simple and responsive.
- Follow the existing project structure.
- Do not modify working features unless necessary.
- Use reusable components.
- Write clean and readable code.

## Backend
- Use the project's existing backend/API.
- Do not create a new backend unless requested.
- Keep API configuration in environment variables.

## UI/UX
- Use a clean modern dashboard.
- Prioritize readability.
- Use consistent spacing, typography, and icons.
- Make screens mobile-friendly.

## Code Rules
- Avoid unnecessary dependencies.
- Explain major changes before implementing them.
- Check existing code before creating new files.
- Do not delete existing functionality without confirmation.
